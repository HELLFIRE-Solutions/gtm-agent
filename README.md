# HELLFIRE AI Solutions — GTM / Sales Agent

Модуль 1 (пріоритет №1). AI-агент для кваліфікації теплих лідів (LinkedIn/реферали — без масового cold email, юридично ризиковано в DACH), персоналізованого аутричу на вручну підібраному списку, та інтеграції з calendar booking.

**Dogfooding:** спочатку працює всередині самої HELLFIRE як реальний sales-інструмент. Тільки після підтвердженої роботи з нього витягується universal-шаблон — конфігурований GTM-agent framework під ICP клієнта, з підключенням до їхньої CRM/email/LinkedIn.

**Відкриті технічні питання:**
- Стек оркестрації агента (LangGraph / власний оркестратор на Claude API / інше)
- Як агент документує legitimate interest для кожного контакту (DSGVO)
- Інтеграція з CRM (HubSpot / Pipedrive / інше)
